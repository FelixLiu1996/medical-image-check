# 医学实验图像与数据查重软件产品需求文档

- 文档版本：0.1
- 状态：待用户评审
- 日期：2026-08-25
- 目标版本：首个可用版本

## 1. 产品定位

本产品是一款面向基础医学实验研究团队的 Windows 本地桌面软件，用于发现实验图像和 Excel 原始数值数据中的完全重复、经过变换的重复、局部复用、高度相似和可疑数值规律，并提供可解释、可定位、可人工复核的证据。

产品是科研质量检查工具，不用于临床诊断，也不自动判定学术不端。

## 2. 用户与使用规模

- 主要用户：自己的基础医学实验研究团队。
- 图像规模：单次约数百至数千张。
- Excel 规模：单文件或多文件，约数千至数万行；标准性能场景按最多约十万个数值单元格估算。
- 平台：Windows 10/11 x64。
- 发布：GitHub 公有仓库，通过 GitHub Release 提供下载。

## 3. 产品原则

1. 完全本地处理，不依赖大模型 API 或云端查重服务。
2. 无 GPU 时核心功能完整可用；兼容 GPU 加速。
3. 永不修改、覆盖或删除用户原始数据。
4. 输出证据、风险和解释，最终结论由研究人员复核。
5. 软件、算法、模型、参数和输入数据指纹可追溯。
6. 需求、实现、测试和变更记录必须支持新窗口直接接手。

## 4. 结果分类

### 4.1 图像结果类型

- 确认重复：文件、解码像素或经过验证的来源内容相同。
- 疑似复用：局部内容相同，但发生裁剪、缩放、旋转、翻转、调色、标注、遮挡或其他编辑。
- 高度相似：不是同一原始图像，但形态或实验表现高度相似，需人工复核。
- 正常关联：同视野不同荧光通道、Merge 关系、同一病理区域不同倍率等预期关系。

### 4.2 Excel 结果类型

- 确认重复：完整数值、数据行列、连续区域或实验组数据相同。
- 疑似复制：只修改少量数值、顺序、倍数、小数位或存在稳定加减乘除关系。
- 统计异常：分布、汇总结果或数值规律异常相似，但不能证明来源相同。

每条结果具有高、中、低风险等级，并显示触发规则和计算证据。

## 5. 项目工作流

### 5.1 项目

用户可以新建、打开和继续项目。项目保存：

- 导入文件及文件夹清单；
- 实验组、通道、视野和面板信息；
- 扫描范围、灵敏度和自定义参数；
- 文件指纹、缩略图和查重特征；
- 任务进度、扫描结果和重复组；
- 人工确认、误报、待定结论和备注；
- 已生成报告及版本信息。

关闭软件后可以继续项目，不要求重新扫描已完成内容。

### 5.2 推荐操作流程

1. 新建或打开项目。
2. 拖入文件、文件夹或多个 Excel。
3. 自动识别或手动设置实验分组。
4. 选择批次内部、组间或历史库扫描。
5. 选择严格、标准、敏感或自定义参数。
6. 开始扫描并查看进度。
7. 浏览、筛选和人工复核结果。
8. 导出报告或将数据加入历史库。

## 6. 图像输入范围

### 6.1 第一版支持

- JPG/JPEG
- PNG
- BMP
- WebP 静态图片
- TIF/TIFF；多页 TIFF 的每一页分别作为图像处理，并保留原文件及页码关系
- 上述格式组成的单图、多面板图、文件夹及多文件夹

### 6.2 第一版不支持

- PDF、Word、PPT 内嵌图片自动提取
- DICOM
- SVS、NDPI 等超大病理切片格式
- 动态 GIF、视频
- 相机 RAW

## 7. 图像扫描范围

- 单张图片内部局部重复检测。
- 同一文件夹或同一导入批次内部全部互查。
- 多个文件夹或实验组之间比较。
- 单个项目内不同时间导入的数据比较。
- 新数据与本地历史图库比较。
- 同一多面板图内部及不同面板之间比较。

不得仅依赖朴素的全量两两精查；应先建立索引召回候选，再进行精细验证。

## 8. 通用图像查重

第一版必须检测：

- 文件完全相同；
- 解码后像素相同但文件格式或元数据不同；
- 压缩、缩放或改变分辨率；
- 调整亮度、对比度、颜色或窗宽窗位类显示变化；
- 旋转、翻转和一定范围的几何变化；
- 裁剪后相同；
- 大图包含小图；
- 两图仅部分区域重叠；
- 增加文字、箭头、标尺、遮挡或局部覆盖；
- 图像内部复制粘贴；
- 医学形态或实验表现高度相似但并非同一来源。

“高度相似”只能作为低或中风险候选，不得仅凭深度模型相似度认定复用。

## 9. 多面板图

- 自动检测规则排列和明显分隔的面板。
- 尝试识别无明显间距或带 A/B/C/D 标签的面板。
- 自动拆分后允许用户调整边界、重新切割、合并和命名。
- 保留面板与原始图片的坐标映射。
- 允许面板内部自查以及面板间、跨文件比较。

## 10. 专项图像检测

### 10.1 Western blot

必须覆盖：

- 整图、面板、泳道、单条带和局部区域复用；
- 同一原始 blot 的不同曝光、裁剪、拉伸、调色和翻转；
- 条带相同但背景被修改；
- 局部擦除、覆盖、移动或拼接；
- 背景纹理、边缘细节和几何一致性验证。

单条带自然相似可能较多，应提供独立灵敏度开关。条带、背景和多个几何证据共同匹配时提高风险。

### 10.2 荧光图像

- 识别同一视野的不同通道。
- 识别单通道与 Merge 图之间的组合关系。
- 同视野不同通道默认标为正常关联，不直接高风险报警。
- 不同实验组复用同一视野时报警。
- 检测单图内部或跨图复制的细胞、组织和局部区域。
- 支持通过文件名、文件夹结构自动推测组别，也支持用户手动指定和复核。

### 10.3 普通病理图片

- 检测同一组织区域、局部裁剪和不同倍率关系。
- 同一区域不同倍率默认标为正常关联信息。
- 区分连续切片结构相似、语义相似和像素级局部复用。
- 检测图像内部复制、修补或跨实验组复用。
- 进行多尺度和必要的染色差异归一化。

### 10.4 其他实验图片

第一版使用通用图像算法检测完全重复、局部重叠和变换后复用，不承诺实验类型专属结构识别。

## 11. 图像灵敏度

- 严格：误报较少，主要显示有明确来源复用证据的结果。
- 标准：默认模式，兼顾局部复用和经过处理的重复。
- 敏感：召回更多高度相似候选，允许较多误报。
- 自定义：调整最小区域、相似度、几何变换和专项检测参数。

Western blot 单条带检测提供独立开关。低可信候选默认折叠，但计入结果数量并可查看。

## 12. 图像结果展示

- 文件名、完整路径、页码或面板位置。
- 相似度、风险等级、结果类型和触发规则。
- 原图并排、同步缩放和局部放大。
- 匹配框、重叠区域、多边形或热力图。
- 叠加、闪烁对比和差异图。
- 检测到的旋转、翻转、缩放、裁剪和位移关系。
- 将互相关联的 A/B/C 图片自动聚合为重复组。
- 逐条标记确认重复、正常关联、误报或待定，并添加备注。
- 重新扫描时继承仍然适用的人工结论。

## 13. Excel 输入范围

- `.xlsx`
- `.xls`
- `.xlsm`，只读取内容，永不执行宏
- `.csv`
- 单个或多个文件
- 默认扫描全部工作表，包括隐藏工作表；结果中标记隐藏状态

文本和日期不参与比较。空白默认忽略。百分比等数值格式按底层完整数值参与比较；格式为日期的数值单元格按日期忽略。

公式读取文件中保存的完整计算结果，不比较公式文本，也不主动执行或重新计算公式。没有缓存结果时跳过对应单元格并报告原因。

## 14. Excel 扫描方式

- 自动识别：根据表头和数据结构推测实验组和数值区域。
- 手动框选：用户选择工作表、实验组和数据区域。
- 全局扫描：扫描所选一个或多个文件中的全部数值单元格，不依赖表格结构。

全局结果必须保留文件、工作表、单元格坐标、完整数值和可见值以便回查。

## 15. Excel 检测规则

### 15.1 直接和结构重复

- 单元格完整数值重复。
- 整行、整列、连续区域或实验组重复。
- 同一文件、跨工作表和跨文件重复。
- 连续数据片段复制。
- 数据顺序打乱后仍然相同。
- 只修改少量数值的疑似复制。
- 均值、标准差等汇总结果异常相同。
- 数据分布高度相似但数值不完全相同。

单独出现相同的 `0`、`1`、`100%` 或其他高频常数默认不报警；它们参与连续序列或稳定运算规律时可以报警。

### 15.2 不同单元格内部的连续数字片段

- 只比较不同数值单元格之间的内部数字片段。
- 不检测同一单元格自身内部是否重复。
- 使用单元格保存的完整真实数值，而不是界面截断的小数位。
- 比较时忽略正负号、小数点、千位分隔符、百分号和科学计数法的显示形式，转为规范数字串。
- 默认连续 4 位开始报警，允许用户调整；首版建议范围为 3 至 12 位。
- 连续 4 位默认低风险折叠，5 至 7 位默认中风险，8 位以上默认高风险。
- 完整数值重复由直接重复规则单独报告。

### 15.3 近似一致

默认容差档位：

- 精确匹配；
- 极高相似：相对误差不超过 0.01%；
- 高相似：相对误差不超过 0.1%；
- 近似：相对误差不超过 1%。

用户可以自定义容差；实现应正确处理接近 0 的数值，避免仅使用相对误差造成异常。

### 15.4 数值变换和运算关系

- 一组数据相差固定倍数。
- 一组数据相差固定加减值。
- 不同小数位或单位换算后的疑似相同。
- 单元格配对加、减、乘、除后接近特定值。
- 整组数据持续满足同一运算关系。
- 默认目标包括任意整数、0、1/100%、10、100、1000，并允许用户自定义。

单次满足运算关系默认低风险；同一规律连续出现 3 次默认中风险，连续出现 4 次以上默认高风险。风险规则和次数允许配置。

### 15.5 结果证据

每条 Excel 结果应显示：

- 两侧文件、工作表和单元格或区域；
- 完整数值及工作表可见值；
- 匹配数字片段；
- 使用的加减乘除、倍数、偏移或排序关系；
- 误差、连续次数、风险等级和规则说明；
- 人工复核结论和备注。

## 16. 历史库

- 建立本地图像及 Excel 特征历史库。
- 支持新数据与历史库比较。
- 默认不自动污染历史库；支持扫描后手动加入、项目级自动加入或只加入人工确认的数据。
- 保存来源项目、路径、文件指纹、特征和人工结论。
- 源文件变化时提示重新索引。
- 支持历史库导出、导入和合并。
- 第一版每台电脑使用独立本地库；不支持多台电脑并发访问中心数据库。

## 17. 原始文件与项目包

- 默认引用原文件，不复制、不修改。
- 用户可以选择将原文件复制到项目中归档。
- 文件移动、删除或改变时显示明确状态。
- 轻量项目包包含配置、索引、缩略图、结果、复核结论和报告，不包含原始文件。
- 完整项目包可选择包含原始文件或归档副本，可在另一台电脑独立复核。
- 项目包具有格式版本、校验信息和迁移机制。

## 18. 扫描任务

- 显示总进度、当前阶段和预计剩余时间。
- 支持暂停、继续和安全取消。
- 支持异常退出后的断点恢复。
- 扫描期间可以查看已经产生的结果。
- 允许限制 CPU、内存和 GPU 资源。
- 完成后提供桌面通知和可选提示音。
- 单个文件失败不得导致整个任务失败。

## 19. 界面

第一版为中文浅色界面，主要页面：

1. 首页：新建项目、最近项目、导入项目包。
2. 项目：文件导入、分组、扫描范围和参数。
3. 结果中心：图像、Excel 和综合结果。
4. 历史库：搜索、添加、移除、重新索引和导入导出。
5. 设置：灵敏度、资源、报告、缓存、模型和软件信息。

第一版保留基本筛选、排序和逐条人工复核。深色模式、自定义标签、高级搜索、批量确认和复核人身份记录暂缓。

## 20. 报告

支持：

- Excel：用于筛选、排序和二次统计。
- HTML：交互查看原图、匹配区域和参数。
- PDF：归档、打印和提交审核。

报告包含：

- 项目及扫描总览；
- 文件数、扫描范围、重复组和风险等级统计；
- 图像缩略图、匹配区域、相似度、变换及人工结论；
- Excel 位置、完整数值、匹配片段、运算关系和误差；
- 软件、算法和模型版本；
- 扫描时间、参数和输入文件指纹；
- 人工复核结论和备注。

允许导出当前筛选结果或全部结果。

## 21. 本地模型和 GPU

- 不接入任何大模型 API。
- 基础算法和基础模型随安装包提供，安装后可完全离线运行。
- 大型专项模型可以作为 GitHub Release 的可选模型包手动导入。
- 自动检测可用 GPU；不可用、初始化失败或显存不足时自动回退 CPU。
- 用户无需安装 Python、CUDA 或开发环境。
- GPU 主要影响性能，不得改变核心功能是否可用。
- 报告记录实际执行设备、模型和后端版本。

## 22. 性能目标

参考环境：Windows 10/11、六核 CPU、16GB 内存、SSD、无独立显卡。

- 普通启动目标不超过约 5 秒。
- 十万个数值单元格的标准扫描目标不超过约 5 分钟。
- 一千张约 2000×2000 图片的首次标准扫描目标为 30 至 60 分钟。
- 已建立索引的数据再次扫描应明显更快。
- 默认内存占用尽量控制在 8GB 以内。
- 扫描任务不应使系统完全失去响应。

以上是参考工程目标，不是所有硬件和全部敏感参数下的绝对承诺。正式验收应固定硬件和测试数据。

## 23. 错误与异常处理

- 损坏或不支持的文件跳过并记录原因。
- 密码保护或加密 Excel 第一版不破解，提示解密后重试。
- `.xlsm` 永不执行宏。
- 公式无缓存结果时跳过并提示。
- 超大常规图片先低分辨率召回，再对候选区域读取原图精查。
- 扫描期间文件变化时标记为已变化并要求重新索引。
- 崩溃日志默认不写入原图或具体实验数值。
- 未完成任务能够恢复，无法恢复时明确说明原因。

## 24. 发布与许可证

- GitHub 公有仓库。
- 项目自有代码采用 Apache-2.0。
- 发布 Windows 安装程序、免安装压缩包、可选模型包、SHA-256、更新说明和已知问题。
- GitHub Actions 自动执行测试和构建。
- 第一版不要求自动更新；用户手动下载新版。
- 商业代码签名暂缓，早期安装程序可能显示未知发布者。
- 第三方代码、模型和资源必须具有明确且与实际分发方式兼容的许可证。
- `THIRD_PARTY_NOTICES.md` 记录组件、版本、来源、许可证、打包状态和必要声明。

## 25. 可复现与版本兼容

- 项目、数据库、项目包、算法结果和模型清单均具有版本号。
- 报告记录软件版本、算法版本、模型版本、参数、输入指纹和执行后端。
- 同一版本、相同参数和相同输入应尽量产生相同结果。
- 数据格式升级提供迁移或明确的向后兼容策略。
- 人工结论继承时必须验证对应文件指纹和算法规则仍然适用。

## 26. 第一版不包含

- 临床试验数据管理和医疗数据安全合规体系。
- 登录、权限、中心服务器和多人并发协作。
- 云端存储、大模型 API 和在线查重服务。
- 自动删除、移动或覆盖重复文件。
- PDF、Word、PPT 自动抽图。
- DICOM、超大病理切片和视频处理。
- 深色界面、高级标签、复杂搜索和批量人工确认。
- 复核人账号和审计身份体系。
- 自动在线更新和商业代码签名。

## 27. 验收要求

### 27.1 功能验收

- 支持范围内的输入、扫描模式、结果复核、历史库、项目包和三种报告均可完成完整流程。
- CPU 环境可执行全部核心流程；GPU 故障能够回退。
- 原始输入文件在扫描前后内容指纹不变。
- 失败文件、公式缺失和任务中断都有明确恢复或说明。

### 27.2 算法验收

需准备包含正例和负例的数据集：

- Western blot：整图、泳道、条带、背景修改及正常相似。
- 荧光：不同通道、Merge、同视野、不同实验组复用和局部复制。

- Excel：完全重复、数字片段、近似值、固定倍数、偏移、运算关系和正常巧合。

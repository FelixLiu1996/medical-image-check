## 阻塞或待定

- 验收样例数据待用户向团队确认。
- 算法准确率与阈值待样例校准。
- GPU 后端和历史库仍需后续 ADR/验证。
- 当前全局感知和局部几何阈值仅通过合成数据验证，不能作为准确率承诺。
- 当前 Western blot 只对明显横向条带行形成自动面板，阈值仅通过合成数据验证；复杂排版、文字标签、弱条带和任意擦除/拼接仍可能漏检或误报。
- 当前 Excel 片段/近似/序列阈值也仅通过合成数据验证；默认 4 位可能产生大量低风险候选。
- Windows 免安装包已通过 Actions 构建与冒烟，仍需干净 Windows 10/11 实机人工验收。

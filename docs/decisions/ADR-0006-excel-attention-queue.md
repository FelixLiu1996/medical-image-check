# ADR-0006：Excel 保留完整线索，并默认展示有界重点候选

- 状态：已接受
- 日期：2026-08-26

## 背景

Alpha 在 13 个真实工作簿的全局扫描中能保留已知阳性，但会生成约 1,800 条结果。主要来源是完整值、数字片段、近似值以及同一列关系被倍数、商和统计规则重复解释。试用用户不可能逐条检查数百至上千条线索；同时，直接删除低风险结果或只保留固定总数又可能隐藏后续调优需要的证据。

工作簿还存在正常的原始列与 `rescaled` 等派生列：派生列有缓存公式结果，表头和同排引用足以说明它是预期换算关系。只根据数值倍数把它标成高风险会误导用户。

## 决策

1. 读取 XLSX/XLSM 时保留最近列标题、标题行和只读公式文本作为本次扫描的内部语义元数据；不执行公式、不比较公式文本，也不把公式写入结果或报告。
2. 数值序列按“文件、工作表、列、最近标题行”分段，避免同一列中上下两个表格区块被拼成一条虚构序列。
3. 明确的顺序号列不进入数值规则。常量和全零序列继续由统一信息量门槛排除；完整值及用户配置的单次运算仍可作为低风险线索保留。
4. 当同排公式大部分引用另一列，或相邻列具有明确的 `rescaled`、`normalized`、百分比、相对值等派生表头时，将受支持的数值关系归类为“正常派生关系”，不进入重点异常队列。
5. 同一列对被多条等价或从属规则命中时，完整结果仍保留各条机器规则；默认重点队列只选择解释力最强的一条，并在证据中记录关联规则。
6. 数据工作区默认显示“重点候选（推荐）”，允许切换到“全部线索”。重点队列只从高/中风险非正常关系中选取，并设置全局 50 条、每工作簿 10 条、每工作表 3 条及每规则族上限；全部线索、报告和反馈数据不因该展示上限被删除。
7. 重点队列是工作量控制和排序结果，不是准确率结论。进入次要线索不表示误报，进入重点候选也不表示学术不端。

## 理由

- 先识别公式和表头语义，可以解决正常派生列被高风险报警的根因。
- 保留全部线索但默认展示有界队列，兼顾可用性、可追溯性和后续算法调优。
- 分来源配额避免单个工作簿或工作表占满首页，同时保留跨文件阳性的机会。
- 不引入固定“真实异常数量”。某一批数据实际确认约 3 处，不代表其他输入也应固定输出 3 条。

## 被否决的方案

- 直接把所有结果截断为固定前 N 条：会静默删除低风险证据和后续反馈素材。
- 只按风险排序：大量偶然长数字片段仍可能占满高风险列表。
- 将全部公式列自动视为正常：公式也可能复制错误或跨组复用，必须要求同排引用或明确派生表头，并仅对受支持关系分类。
- 在没有标注集时尝试把重点队列等同于真实异常：无法给出可信准确率。

## 后果

- 扫描算法版本升级为 `excel-advanced-4`；旧算法版本的反馈标记不自动继承。
- 项目 schema 不变，新增的注意力层级和归并信息使用既有递归 `Finding.details` 保存。
- 旧项目结果没有注意力层级时，界面以高/中风险作为兼容性重点候选；重新扫描后使用新策略。
- 公式元数据只存在于扫描内存，项目和反馈清单不会保存原公式。

# ADR-0001：核心查重完全本地运行

- 状态：已接受
- 日期：2026-08-25

## 背景

产品需要在 Windows 桌面处理数百至数千张实验图片和多个 Excel。用户询问是否需要接入大模型 API，并确认第一版不需要。

## 决策

- 核心图像和 Excel 查重完全在本地运行。
- 不接入大模型 API 或云端查重服务。
- 可使用本地传统算法和本地视觉模型。
- CPU 是完整功能基线，GPU 只提供加速。
- 模型随基础安装包或可选 GitHub 模型包分发。

## 原因

- 局部重叠需要像素和几何证据，通用大模型不适合作为最终判定。
- 本地算法更容易复现、版本化和校准阈值。
- 避免批量 API 成本、上传耗时和外部服务变化。
- 保证无网络和无 GPU 环境仍可使用。

## 后果

- 安装包或模型包可能较大。
- CPU 扫描速度慢于 GPU。
- 必须维护模型版本、许可证、CPU/GPU 后端和兼容性测试。
- 未来可以增加可选结果解释能力，但不得替代本地核心判定。

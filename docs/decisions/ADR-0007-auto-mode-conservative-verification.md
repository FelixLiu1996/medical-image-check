# ADR-0007：自动模式采用保守路由与二次内容验证

- 状态：已接受
- 日期：2026-09-03

## 背景

124 例 post-unseal validation 的首轮 Panel 扫描产生大量候选。医学人员抽样复核的 32 组阴性候选全部判为“不重复”，主要模式不是同一类阈值偏差，而是科学图表、文字、坐标轴和复合版式被通用局部或医学专项算法误当成图像内容复用。单纯提高所有模式的统一阈值会同时伤害用户主动选择 Western blot、Dot blot、荧光或病理专项时的召回，也不能解决“候选类型本来就错了”的路由问题。

## 决策

1. `AUTO` 模式必须比显式专项模式更保守。自动路由和精查可使用额外准入条件；用户明确选择专项模式时继续使用该专项原有的宽松范围。
2. 通用局部几何命中不能只依赖关键点和 RANSAC。程序在恢复出的两个匹配区域上追加灰度、高频与梯度内容一致性验证；双方都是白底低色度版式时抑制候选。
3. 小区域内容候选增加最低置信度、低色度 SIFT 重投影误差和白底细文字片段约束，避免标签、坐标轴和排版碎片进入复核队列。
4. Western blot 自动模式要求候选符合横向条带行几何，并具有足够的背景或结构证据；条带行聚类容差不再随整页高度放大。
5. Dot blot 自动模式对局部外观、最低单斑点相似度和短序列布局误差使用更严格门槛；显式 Dot blot 模式保留原阈值。
6. 荧光和病理自动准入排除明显白底复合版式、统计图和深色非组织页面，同时保留紧凑小图和彩色组织的已知回归。
7. 所有阈值调整必须同时回归旧 33 条开发集、29 组确认阳性关系、医生复核的 32 组阴性候选和完整仓库测试。由于这些样本已参与诊断，它们只能作为 validation/regression，不能作为独立 test 或对外准确率。

## 理由

- AUTO 的职责是从混合科研图片中选择可信算法路径，错误路由本身就应被视为误报来源。
- 几何一致只说明若干关键点可以拟合变换，不能证明匹配区域的实际内容相同；追加内容验证能直接针对版式和文字伪相似。
- 显式模式表达了用户对图片类型的先验，因此不应被 AUTO 为降误报增加的全部保守条件一起屏蔽。
- 分层验证保持规则可解释，不需要在当前少量反馈上训练带权重的机器学习模型。

## 被否决的方案

- 只提高统一置信度阈值：无法区分真实低分关系与错误路由，高概率造成召回下降。
- 只修改 Panel 拆分：抽样误报同时包含统计图、文字和专项错路由，拆分不是唯一原因。
- 用 32 组反馈立即训练分类模型：样本量小且来自有界、案例均衡抽样，分布不足以支持稳定的监督学习权重。
- 把本轮调优后的 124 例结果当作独立 test：同批数据已经用于候选生成、错误分析和阈值选择，会产生数据泄漏。

## 后果

- 算法版本升级为 `generic-image-local-4+western-blot-3+dot-blot-5+fluorescence-2+pathology-3+panel-split-1+excel-advanced-4`；旧算法版本上的反馈不会自动继承到新结果。
- 每个通用图像特征额外保留最长边不超过 512 像素的灰度和色度验证图，增加有限内存与计算开销。
- AUTO 候选数应明显下降，但 29 组确认关系的低基线不会仅靠降误报自动改善；端点配对、区域定位和 Panel 边界仍需独立优化。
- 下一轮上线判断仍必须使用从未参与本轮调参、按 `source_group` 隔离的新测试集。

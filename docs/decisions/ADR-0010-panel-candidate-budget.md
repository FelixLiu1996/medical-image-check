# ADR-0010：Panel 扫描按原图对限制候选数量

- 状态：已接受
- 日期：2026-09-05

## 背景

`panel-split-3` 在 35 张完整 Figure 人工标注上明显改善了拆分召回，但更细的 Panel 会放大重复验证的组合空间。医生已复核的 28 个阴性案例在新拆分下产生 2,077 条候选，其中 1,706 条来自荧光同通道规则；最严重案例的 641 条结果中，547 条是同一原图内部组合。完整拆分本身可能正确，不能为了控制结果数重新合并这些 Panel。

## 决策

1. 候选经临时 Panel 扫描并回映到原图后，以“规则 ID + 原图路径组合”为独立分组。
2. `suspected_reuse` 和 `high_similarity` 每组只保留风险、置信度最高的 3 条；精确重复和正常关系不受该预算限制。
3. 每条被保留的密集组候选记录组内总数、排名、上限和省略数，保证结果可审计。
4. 预算只作用于启用 Panel 拆分的扫描，不改变整图模式、拆分边界或底层验证阈值。
5. 后续仍需分别优化 AUTO 类型路由和匹配精度；候选预算是工作量与公平性保护，不得表述为 Precision 提升。

## 理由

- 按原图对而非全局截断，可防止一个高密度 Figure 挤掉其他来源组合。
- 按规则独立保留可以维持 Western、荧光、病理和通用检测器的证据多样性。
- 当前 29 组阳性和 32 组阴性已参与开发，不适合训练带权重模型；有界、可解释的后处理更符合当前样本规模。

## 后果

- 算法版本增加 `panel-candidate-budget-1`。
- 阳性按案例完整扫描的候选总数由 1,138 降为 95。后续按“来源路径 + Finding 实际证据区域覆盖关系端点至少 50%”重新审计，确认预算前后均保留 11/29 组，而不是早期按不稳定临时 Panel ID 误记的 6/29；该口径仍不等同于逐对裁剪 matcher 的 13/29。
- 28 个已复核阴性案例的冻结原始结果可确定性重排为 2,077 -> 296；最严重的 `eval-097` 已实际端到端验证为 641 -> 17，并记录省略 624 条。
- 这些样本直接参与预算选择，只能作为 validation/regression；不能据此报告独立 Precision、F1 或上线达标。

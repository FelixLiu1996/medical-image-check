# 路线图

## 已完成：需求与工程基础

- 用户确认 PRD 0.1
- 建立 Python/PySide6 分层工程
- 建立基础 UI、精确图片/Excel 扫描和 CI

## 当前：基础闭环

- 首轮用户实际体验问题已完成本地修复，当前等待 Windows/Linux CI、portable 和干净 Windows 实机回归
- 已将项目清单接入 UI，并保存/恢复最近扫描结果
- 已支持 Excel、单文件 HTML 和中文 A4 PDF 三种本地报告
- 已实现后台扫描协作式暂停、继续和安全取消，下一步补持久化任务断点与崩溃恢复
- 已建立 Windows 免安装构建并通过 Windows runner 构建/冒烟，等待干净机器人工验证
- 已实现解码像素指纹和整体感知近似候选层
- 已实现局部关键点候选索引、裁剪/重叠几何验证和基础证据预览
- 已实现 Excel 数字片段、可调近似容差、单次/连续运算、连续片段、乱序、少量修改、二维区域、稳健线性和低风险统计规则基线
- 已将图片内容类型、Excel 容差、运算目标和连续风险阈值接入 GUI、项目 schema 6 及三种报告；当前 Excel 只执行全局扫描，自动识别和手动框选待后续实现
- 已实现 Excel 全零/常量/零乘积等低信息量关系降噪、证据强度排序和跨工作簿/工作表公平选取，并增加左右原表上下文与命中高亮
- 已实现 Western blot 明显横向面板/条带、背景纹理、曝光/翻转和同图 Copy-Move 基线，下一步用验收数据调优并补复杂面板/局部编辑
- 已实现 Dot blot 斑点排列在裁剪、缩放、灰度/对比度变化下的复用候选，并增加自动/显式专项路由以减少串类误报
- 已实现荧光同视野/通道、单通道与 Merge 关系，以及同通道复用候选基线
- 已实现普通病理组织掩膜、多尺度局部匹配和不同倍率正常关系基线
- GUI 证据预览已支持聚焦匹配区域和复制摘要
- 下一项算法工作进入真实/授权数据校准、实验组/连续切片语义边界与专项证据交互优化
- 获取或制作算法验收数据
- 轻量“准确/误报/正常关联”反馈已确定为后续算法调优数据来源，但暂缓开发；不建设强制审核流程

## 已记录但暂缓

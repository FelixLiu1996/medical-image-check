GitHub CI 在 Windows 执行全部测试；Linux 用于验证无界面核心逻辑，不执行 Windows 产品界面的 Qt 冒烟测试。

Windows portable 工作流在源代码测试后构建 standalone 目录，并执行打包程序的 `--smoke-test`；该模式除创建/关闭窗口外，还在临时目录实际生成 Excel、HTML、PDF 三种报告并检查文件签名，用于发现 ReportLab/Pillow 或模板漏打包。它仍不能代替干净 Windows 10/11 人工扫描、字体显示、打印与导出验收。

PDF 本地排版验收使用软件生成包含中文总览、结果表、荧光图像证据和扫描提示的 A4 样例，通过 Poppler 渲染全部页面并目视检查；同时用 pypdf 验证标题、结果、证据和提示的中文文本层可检索。Windows 仍需验证系统微软雅黑/宋体发现与不同阅读器/打印机兼容性。

## 测试层次

1. 单元测试：规范化、哈希、数值容差、规则评分、版本迁移。
2. 集成测试：图片/Excel 导入到结果、历史库和报告完整流程。
3. 黄金数据测试：固定输入、参数和版本得到稳定结果。
4. 算法验收：正例召回、负例误报、定位误差和风险分级。
5. 性能测试：CPU/GPU 时间、内存、磁盘、索引和恢复。
6. 桌面端测试：安装、免安装、升级、异常退出和 Windows 兼容。
7. 报告测试：Excel/HTML/PDF 内容一致和视觉可读。

## 必测场景

### 图像

- 完全相同、格式变化和元数据变化。
- 压缩、缩放、旋转、翻转、调色、裁剪和标注。
- 局部重叠和单图 Copy-Move。
- 局部候选索引在数百/数千图规模下的召回、运行时间和峰值内存。
- Western blot 泳道、条带、背景及局部编辑。
- Dot blot 斑点缺失/伪影、弱斑点、近连续局部子集、裁剪、缩放、旋转、镜像、灰度和对比度变化，以及相同排列但局部内容不同的负例。
- 荧光同视野通道、Merge、跨组复用和正常负例。
- 病理不同倍率、连续切片、局部复用和形态相似负例。
- CPU/GPU 结果一致性和 GPU 回退。

### Excel

- xlsx/xls/xlsm/csv 和隐藏工作表。
- 公式缓存存在、缺失及宏不执行。
- 完整数值、连续区域、顺序打乱和少量修改。
- 不同单元格的 4 位以上数字片段。
- 0.01%、0.1%、1% 容差边界和接近 0 的值。
- 固定倍数、偏移、加减乘除目标和偶然巧合负例。
- 全零、常量、身份运算及前序工作表占满结果上限的降噪/公平性场景。
- 原始列与同排公式/`rescaled` 派生列的正常关系，以及相似表头但无派生关系的负例。
- 跨规则重复解释只在重点队列保留一项、全部线索不丢失，以及全局/工作簿/工作表配额边界。
- 文本、日期、空白、加密文件和损坏文件。

## Alpha 真实样例回归（不入库）

- 42 个公众号案例最终固定 34 对通用 validation：25 对阳性、9 对阴性。优化前合并基线为 13 TP/5 FP/12 FN/4 TN；针对已知统计图/组合版式误报和小区域漏检开发 `generic-image-local-2` 后，同集回归为 25 TP/0 FP/0 FN/9 TN。由于这 34 对参与了错误分析和阈值开发，该结果只用于开发回归，不是独立 test 或可对外宣传的准确率。
- `generic-image-local-2` 合成回归覆盖白底科学图表布局抑制、低纹理小条带位移/翻转、显微区域镜像和无关区域拒绝；另以 48 张独立生成的无关灰度小条带形成 1,128 个可能图片对，输出 0 条小区域复用结果，端到端约 4.5 秒。该压力测试验证候选有界和常见无关小图降噪，不代表真实数据 specificity。
- 第一版医学图片逐对 validation 共 39 对：26 对阳性、13 对阴性，覆盖 Western blot、免疫荧光、普通病理和细胞明场图；Dot blot 按用户决定暂缓。去除可见彩框并优先换用未画框原图后，`western-blot-1` 基线为 TP=11、FP=1、FN=15、TN=12；`western-blot-2` 定向修正后为 TP=16、FP=0、FN=10、TN=13（precision 1.000、recall 0.615、specificity 1.000）。这是同一小样本上的开发回归，不是正式准确率；全部样例仍在 validation。
- `western-blot-2` 在 11 对 Western validation 上为 7 TP/0 FP/0 FN/4 TN；医学人员确认的 5 个原 FN 均已检出、1 个原 FP 已排除，Casp11/NEDD4 目标条带及其 beta-actin 困难阴性仍被正确排除。免疫荧光仍为 5 TP/0 FP/4 FN/4 TN；病理为 1 TP/0 FP/1 FN/5 TN；明场/通用为 3 TP/0 FP/5 FN，当前尚无该类独立阴性。条带数量差异不作为直接排除规则。
- 通用逐对评测器支持整图、同图双区域、不同文件双区域、逐类型检测、Western 单条带开关、来源组 split 隔离和分类型指标，格式见 `docs/IMAGE_PAIR_EVALUATION.md`。真实图片、裁剪图、本地清单和完整结果均位于 Git 忽略目录，不进入仓库。
- 用户提供的 4 张同源 Dot blot 图片仅在本地只读回归：`dot-blot-2` 自动模式输出 6 组两两 Dot blot 关系且没有其他专项串类，无读取问题；耗时约 1.8 秒。样本量过小，不用于计算准确率。
- Dot blot 等间距负例合成微基准：25 张独立四斑点图片提取 28 个阵列候选约 1.6 秒、验证约 2.3 秒，输出 0 条专项结果；该微基准只验证候选上限与常见排列降噪，不代表真实数据性能或准确率。
- Dot blot 真实/公开授权样本采用 `docs/DOT_BLOT_EVALUATION.md` 的本地清单逐对标注并按来源组隔离；仓库只保存评测器和合成测试，不保存真实图片或本机清单。
- 用户提供的 13 个 Excel 工作簿仅在本地只读回归：`excel-advanced-4` 默认参数输出 1,775 条全部线索、22 条正常派生关系和 50 条重点候选；MOESM9 连续片段、MOESM14 配对和为 2、MOESM15 结构重复均保留在重点队列，读取与检测约 6.36 秒。修复前为 9,864 条，上一算法版本约 1,800 条。
- 真实样例路径和内容不得写入测试夹具、提交记录、报告示例或公有 Release；后续仍需要授权且可公开或内部保管的独立正负例验收集。

## 性能基准

至少记录：机器配置、软件/模型/算法版本、参数、冷启动/热启动、索引时间、精查时间、峰值内存、磁盘增长和 CPU/GPU 利用率。

`0.1.0a12` 起，每次完成扫描都会生成 performance schema 1：记录总时长、扣除协作暂停后的有效运行时长，以及输入收集、图片解码、通用/专项特征与验证、Excel 读取/规则和结果整理等实际阶段。`items` 是阶段特定的输入或输出计数，只能辅助解释同一阶段，不能直接跨阶段比较工作量。GUI 可导出 JSON；文件不包含原始数据、输入路径、查重位置或结构化证据。

首个真实 GPU 验证环境为 Windows 10/11 + NVIDIA GeForce RTX 3080 Ti。当前 `0.1.0a12` 只探测 GPU/驱动/OpenCV CUDA 状态并运行 CPU，不进行 CUDA 计算。RTX 实测应先以当前 CPU 后端生成图片和 Excel 基线；后续 GPU 后端加入后，用同一输入、参数和算法版本比较候选集合、阶段耗时、峰值显存及强制 CPU 回退。macOS 开发机和普通 GitHub Windows runner 可以验证接口、探测失败隔离、CPU 路径和打包，但不能替代真实 NVIDIA CUDA 验收。

当前仅有候选索引微基准：macOS ARM64/Python 3.12.13 中，为 2000 个合成图片项各生成 96 个随机 ORB 形状描述子，单独建立局部倒排候选索引用时约 2.9 秒，进程峰值 RSS 约 304 MiB，且未产生随机候选。该数字不包含图片解码、ORB 提取和几何精查，不能替代真实图片端到端性能验收。

Excel 合成微基准：同一环境中，20,000 个不同 11 位随机整数的数字片段检测约 1.6 秒并产生约 53,000 条候选；近似/序列高级规则约 0.8 秒并产生约 8,000 条候选，进程峰值 RSS 约 225 MiB。默认 4 位会自然产生大量低风险结果，该数字用于暴露结果膨胀风险，不代表真实实验表格分布或端到端报告时间。

`excel-advanced-2` 额外压力检查在同一环境中直接构造 80,000 个数值单元格（10,000 行 × 8 列），新结构/运算/统计规则约 3.3 秒完成，进程最大 RSS 约 95 MiB，并因人工数列中的精确十倍关系达到单次运算规则 300 条上限。该数字不含工作簿读取、旧片段/近似规则和报告生成，只用于验证实现不会对数万行直接执行无界两两计算。

Western blot 合成微基准：同一环境中，500 张 180×360 随机背景/随机条带图片提取出 542 个面板候选，特征提取约 2.3 秒；分段索引召回约 31,900 对候选并完成验证约 0.5 秒，进程峰值 RSS 约 101 MiB，最终产生 1 条低风险候选。该集合是专门观察候选膨胀的人工压力数据，不包含文件读取、通用图片算法，也不代表真实 Western blot 的准确率或端到端速度。

荧光/病理合成微基准：同一环境中，300 张 180×240 随机稀疏荧光图提取 290 个有效页面约 1.0 秒，候选索引与验证约 0.1 秒；150 张 240×240 随机染色形态图提取 279 个有效组织窗口约 0.7 秒，候选索引与验证约 0.02 秒，两组无关随机输入均未产生结果。该测试在内存中直接传递像素，不包含文件解码、通用算法或 GUI/报告；真实组织密度、重复视野和文件名分组可能增加候选数，不能用作准确率或端到端性能承诺。

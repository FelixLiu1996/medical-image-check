# 算法方案初稿

状态：方向已确认，具体模型、阈值和准确率待验收数据校准。

## 总体策略

采用多阶段混合方法，不使用单一相似度模型直接判定：

1. 规范化输入并计算快速指纹。
2. 使用哈希、局部/全局特征或倒排索引召回少量候选。
3. 对候选执行几何、像素、序列或运算关系验证。
4. 融合多条证据形成结果类型和风险等级。
5. 聚类关联对象并交给人工复核。

## 通用图像

| 目标 | 候选方法 | 验证方法 |
| --- | --- | --- |
| 文件相同 | SHA-256 | 文件大小与哈希 |
| 像素相同 | 规范化像素指纹 | 逐像素或块级验证 |
| 整图近似 | 感知哈希、全局特征 | 配准后 SSIM/差异 |
| 裁剪/缩放/旋转 | 局部关键点 | RANSAC 仿射/单应验证 |
| 局部重叠 | 密集图块特征 | 区域一致性与重叠多边形 |
| 单图复制 | Copy-Move 候选 | 排除邻域后验证一致变换 |
| 语义相似 | 本地深度特征向量 | 仅作为候选，不单独定高风险 |

索引用于将复杂精查限制在候选集合，避免随图片数量进行全量高成本比较。

### 已实现的整体图像基线

1. 对文件内容计算 SHA-256，报告字节完全相同的文件。
2. 使用 OpenCV `IMREAD_UNCHANGED` 解码；TIF/TIFF 使用多页解码并保留页码。灰度扩展为三通道，完全不透明的 Alpha 通道被移除，然后以数据类型、形状和像素内容计算解码像素 SHA-256。
3. 为 64×64 灰度缩略图计算 pHash 和 dHash，并覆盖旋转 90/180/270 度及四种镜像/旋转组合。
4. 将 64 位哈希分成 8 个分段建立倒排候选索引，再对候选计算汉明距离、宽高比兼容性和去均值/方差后的缩略图余弦相似度。
5. 低纹理图片（缩略图标准差小于 3）不进入感知候选，避免空白背景产生候选爆炸和无意义误报。

当前整体近似候选要求 pHash 距离不超过 10、dHash 距离不超过 12、标准化缩略图相似度不低于 0.92。pHash 不超过 4、dHash 不超过 6 且相似度至少 0.98 时标为中风险，其余通过候选标为低风险。感知相似绝不单独给出高风险。

### 已实现的局部几何基线 `generic-image-local-1`

1. 图片最长边超过 1600 像素时先等比例缩小用于特征提取，原始坐标按比例恢复；对灰度图执行局部对比度增强后，每页最多提取 1200 个 ORB 关键点和二进制描述子。
2. 关键点按 4×4 空间网格交错排序，候选索引优先使用每张图片空间分散的前 96 个描述子，避免高响应点全部集中在一个小区域。
3. 每个候选描述子抽取 8 个 16 位子签名建立倒排索引。只有共享子签名且完整描述子汉明距离不超过 56 的图片对才累计投票；至少 3 个不同描述子投票后进入精查。单个高频桶最多保留 64 项，限制重复纹理造成的候选膨胀。
4. 精查使用 ORB 汉明距离、0.80 比率检验和双向一致匹配，单个匹配距离不超过 64；至少 8 个双向匹配点后才尝试几何模型。
5. 使用 RANSAC 估计相似仿射和单应模型，阈值取 3 像素与较小图片对角线 0.4% 中的较大值。结果至少需要 8 个几何内点、50% 内点比例；匹配框在两图中的较大覆盖率至少 8%，较小覆盖率至少 1%。
6. 输出模型类型、双向匹配点、内点数/比例、中位重投影误差、两侧矩形区域、覆盖率、第二张图到第一张图的局部尺度与旋转。置信度至少 0.72 时为中风险，否则为低风险；当前不凭局部候选自动给出高风险。
7. 已被文件、解码像素或整体感知规则报告的同一图片对不再重复生成局部结果。

上述候选层避免对数百至数千张图片做朴素全量 ORB 两两匹配。描述子仍只保存在单次扫描内存中，尚未写入项目缓存或历史库。

以上阈值是合成测试基线，不是最终准确率承诺。当前已覆盖大图包含小图、旋转/缩放/压缩后的裁剪，以及两张裁剪图的部分重叠；极小区域、低纹理区域、强遮挡或重复结构仍可能漏检或误报。文字遮挡专项处理、单图 Copy-Move、多面板拆分和三类医学图像专项证据尚未实现，不能通过单纯放宽阈值代替。

## Western blot

- 灰度和背景规范化。
- 面板、泳道和条带候选检测。
- 强度投影、形态学、边缘及纹理特征。
- 泳道/条带局部相关、结构相似和几何验证。
- 背景纹理作为高价值来源证据。
- 识别曝光、裁剪、拉伸、翻转、遮挡和局部修改。
- 单条带相似默认低可信，多条带和背景共同匹配提高可信度。

## 荧光图

- 使用结构特征和配准识别同视野。
- 检查单通道与 Merge 的组合关系。
- 亮度、颜色和对比度归一化。
- 密集局部特征检测复制区域。
- 结合文件名、目录和用户分组区分正常关联与跨组复用。

## 病理图

- 组织区域掩膜和背景排除。
- 多尺度图像金字塔与图块特征。
- 必要的染色/颜色归一化。
- 近邻召回后执行跨尺度几何验证。
- 区分同区域不同倍率、连续切片相似和像素级复用。

## Excel

| 目标 | 建议方法 |
| --- | --- |
| 完整数值/行列/区域 | 规范数值、哈希和滚动哈希 |
| 连续数字片段 | 4 位及以上 n-gram 倒排索引 |
| 近似数值 | 绝对与相对容差分桶 |
| 顺序打乱 | 多重集合指纹、排序指纹、MinHash 候选 |
| 固定倍数/偏移 | 稳健回归或 RANSAC 验证 `B≈aA+b` |
| 特定运算目标 | 补数/目标反向索引，避免全量两两暴力计算 |
| 分布异常相似 | 相关、秩、分布距离等统计证据 |

## 风险评分原则

- 可重复的像素或几何证据高于语义相似度。
- 多个独立证据共同支持时提高风险。
- 常见值、短数字片段和单次运算巧合保持低风险。
- 正常实验关系能够被单独分类，不与可疑复用混合。
- 每个风险等级必须能够解释触发规则，不能只显示黑箱分数。

## 可复现要求

- 记录算法、模型、参数、随机种子、执行后端和输入指纹。
- CPU/GPU 数值差异不得造成结果类型大范围不一致。
- 阈值升级应具有算法版本，并说明人工结论能否继承。

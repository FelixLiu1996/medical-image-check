# 算法方案初稿

状态：方向已确认，具体模型、阈值和准确率待验收数据校准。

## 总体策略

采用多阶段混合方法，不使用单一相似度模型直接判定：

1. 规范化输入并计算快速指纹。
2. 使用哈希、局部/全局特征或倒排索引召回少量候选。
3. 对候选执行几何、像素、序列或运算关系验证。
4. 融合多条证据形成结果类型和风险等级。
5. 聚类关联对象并交给人工复核。

## 通用图像

| 目标 | 候选方法 | 验证方法 |
| --- | --- | --- |
| 文件相同 | SHA-256 | 文件大小与哈希 |
| 像素相同 | 规范化像素指纹 | 逐像素或块级验证 |
| 整图近似 | 感知哈希、全局特征 | 配准后 SSIM/差异 |
| 裁剪/缩放/旋转 | 局部关键点 | RANSAC 仿射/单应验证 |
| 局部重叠 | 密集图块特征 | 区域一致性与重叠多边形 |
| 单图复制 | Copy-Move 候选 | 排除邻域后验证一致变换 |
| 语义相似 | 本地深度特征向量 | 仅作为候选，不单独定高风险 |

索引用于将复杂精查限制在候选集合，避免随图片数量进行全量高成本比较。

### 已实现的通用图像基线 `generic-image-baseline-1`

1. 对文件内容计算 SHA-256，报告字节完全相同的文件。
2. 使用 OpenCV `IMREAD_UNCHANGED` 解码；TIF/TIFF 使用多页解码并保留页码。灰度扩展为三通道，完全不透明的 Alpha 通道被移除，然后以数据类型、形状和像素内容计算解码像素 SHA-256。
3. 为 64×64 灰度缩略图计算 pHash 和 dHash，并覆盖旋转 90/180/270 度及四种镜像/旋转组合。
4. 将 64 位哈希分成 8 个分段建立倒排候选索引，再对候选计算汉明距离、宽高比兼容性和去均值/方差后的缩略图余弦相似度。
5. 低纹理图片（缩略图标准差小于 3）不进入感知候选，避免空白背景产生候选爆炸和无意义误报。

当前整体近似候选要求 pHash 距离不超过 10、dHash 距离不超过 12、标准化缩略图相似度不低于 0.92。pHash 不超过 4、dHash 不超过 6 且相似度至少 0.98 时标为中风险，其余通过候选标为低风险。感知相似绝不单独给出高风险。

以上是合成测试基线，不是最终验收阈值。当前尚未实现裁剪/局部重叠、文字遮挡后的局部验证、Copy-Move、多面板拆分和三类医学图像专项证据；这些必须依赖局部特征与几何验证，不能通过放宽全局哈希阈值代替。

## Western blot

- 灰度和背景规范化。
- 面板、泳道和条带候选检测。
- 强度投影、形态学、边缘及纹理特征。
- 泳道/条带局部相关、结构相似和几何验证。
- 背景纹理作为高价值来源证据。
- 识别曝光、裁剪、拉伸、翻转、遮挡和局部修改。
- 单条带相似默认低可信，多条带和背景共同匹配提高可信度。

## 荧光图

- 使用结构特征和配准识别同视野。
- 检查单通道与 Merge 的组合关系。
- 亮度、颜色和对比度归一化。
- 密集局部特征检测复制区域。
- 结合文件名、目录和用户分组区分正常关联与跨组复用。

## 病理图

- 组织区域掩膜和背景排除。
- 多尺度图像金字塔与图块特征。
- 必要的染色/颜色归一化。
- 近邻召回后执行跨尺度几何验证。
- 区分同区域不同倍率、连续切片相似和像素级复用。

## Excel

| 目标 | 建议方法 |
| --- | --- |
| 完整数值/行列/区域 | 规范数值、哈希和滚动哈希 |
| 连续数字片段 | 4 位及以上 n-gram 倒排索引 |
| 近似数值 | 绝对与相对容差分桶 |
| 顺序打乱 | 多重集合指纹、排序指纹、MinHash 候选 |
| 固定倍数/偏移 | 稳健回归或 RANSAC 验证 `B≈aA+b` |
| 特定运算目标 | 补数/目标反向索引，避免全量两两暴力计算 |
| 分布异常相似 | 相关、秩、分布距离等统计证据 |

## 风险评分原则

- 可重复的像素或几何证据高于语义相似度。
- 多个独立证据共同支持时提高风险。
- 常见值、短数字片段和单次运算巧合保持低风险。
- 正常实验关系能够被单独分类，不与可疑复用混合。
- 每个风险等级必须能够解释触发规则，不能只显示黑箱分数。

## 可复现要求

- 记录算法、模型、参数、随机种子、执行后端和输入指纹。
- CPU/GPU 数值差异不得造成结果类型大范围不一致。
- 阈值升级应具有算法版本，并说明人工结论能否继承。

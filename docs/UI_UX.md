# UI 与操作流程初稿

状态：基础项目与扫描闭环已实现，完整信息架构仍待迭代。

当前窗口支持新建、打开、保存和另存项目，添加文件/文件夹，后台扫描，进度与结果表格，以及导出基础 Excel 报告。项目重新打开后恢复输入路径、最近扫描结果和扫描提示；已有保存路径的项目在扫描完成或报告导出后自动保存。

输入路径发生变化时，旧扫描结果立即失效并禁止导出，必须重新扫描。关闭、新建或打开其他项目之前若存在未保存更改，界面提供保存、放弃和取消三种选择。

当前 Alpha 图片结果包含文件完全相同、解码像素相同、整体感知近似、经过 RANSAC 验证的局部裁剪/重叠，以及 Western blot、荧光和病理专项候选；Excel 包含完整数值、整行重复、连续数字片段、近似值及连续列倍数/偏移/目标关系。选择结果后，图片可并排预览匹配区域；Western blot 摘要显示匹配条带数、结构/几何/背景/掩膜证据，荧光摘要显示中文关系、角色/通道、结构、前景重叠、互信息与配准位移，病理摘要显示中文关系、组织结构/掩膜、倍率、尺度比与变换；Excel 可查看匹配片段、完整值、读取值、误差、关系参数和配对结果摘要。

项目界面提供“连续数字片段最短报警位数”3–12 调节，默认 4；同时提供“检测 Western blot 单条带相似”开关，默认关闭并提示高误报风险。修改任一设置都会立即使旧扫描结果失效，并随项目保存和恢复。

当前证据区是第一版静态预览，尚不支持同步缩放、拖动、逐匹配点/多边形显示、叠加闪烁、差异图和逐条人工复核。

## 通用原则

- 第一版只提供中文浅色界面。
- 长任务始终显示状态、阶段、进度和可用操作。
- 高风险不使用断言式语言，明确提示需要人工复核。
- 文件错误和算法限制就地说明，不只写入日志。
- 保持原文件只读状态可见。

## 页面

### 首页

- 新建项目
- 打开项目
- 最近项目
- 导入项目包
- 软件、模型和历史库状态

### 项目

- 拖拽文件和文件夹
- 输入清单、支持状态和失败原因
- 自动分组与手动框选
- 扫描模式和灵敏度
- 预估工作量与资源设置

### 任务

- 总体和阶段进度
- 当前处理对象
- 预计剩余时间
- 暂停、继续、取消
- 已产生结果入口

### 结果中心

- 图像、Excel、综合三个视图
- 基本风险、类型、文件和状态筛选
- 重复组列表
- 图像并排、叠加、闪烁、差异和匹配区域
- Excel 两侧位置、值、片段、关系和误差
- 确认重复、正常关联、误报、待定和备注
- 导出当前筛选或全部结果

### 历史库

- 查看来源和索引状态
- 添加、移除、重新索引
- 导出、导入和合并

### 设置

- 图像与 Excel 默认灵敏度
- CPU/GPU、线程、内存和缓存
- 模型列表、版本和许可证
- 报告默认项
- 日志和软件信息

## 暂缓

- 深色模式
- 自定义标签
- 高级全文搜索
- 批量人工确认
- 账号和复核人身份

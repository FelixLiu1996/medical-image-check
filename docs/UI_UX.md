# UI 与操作流程初稿

状态：图片/数据双入口、基础扫描闭环和轻量反馈已实现；不建设重型复核信息架构。

Alpha `0.1.0a18` 使用现代化中文浅色首页，首页首先提供“图片查重”和“数据查重”两个明显入口。用户进入工作区后可直接选择若干文件或文件夹并扫描，不要求预先创建或理解项目；新建、打开、保存和另存项目保留在顶部及文件菜单中，作为恢复输入、参数、最近结果和报告的辅助能力。打开旧算法版本的项目时保留历史结果，同时明确提示重新扫描。

图片工作区只允许直接选择 JPG/JPEG/PNG/BMP/WebP/TIFF，显示图片专项参数、图片候选和双图证据；数据工作区只允许直接选择 XLSX/XLS/XLSM/CSV，显示数字片段、容差、运算目标、连续关系参数、数据候选和数值证据。选择文件夹时由扫描服务按当前工作区过滤，另一类文件不会计入本次扫描，也不会执行另一套检测器。打开旧项目时根据已有直接文件和最近结果数量自动选择更匹配的工作区；项目格式不因纯界面模式升级。

当前窗口支持后台扫描及安全暂停/继续/取消、进度与结果表格，以及导出 Excel、HTML、PDF 三种报告。项目重新打开后恢复输入路径、最近扫描结果和扫描提示；已有保存路径的项目在扫描完成或报告导出后自动保存。

扫描成功后状态栏显示扣除暂停时间的有效运行时长和当前计算后端；若探测到 NVIDIA GPU，同时显示首个设备名称，但这不代表当前已经使用 GPU。输入区提供“导出性能诊断”，仅在当前结果含性能画像时可用，输出 JSON 机器/GPU 信息和分阶段耗时，不包含原始文件、输入路径、查重位置或证据内容。

输入路径发生变化时，旧扫描结果立即失效并禁止导出，必须重新扫描。关闭、新建或打开其他项目之前若存在未保存更改，界面提供保存、放弃和取消三种选择。

当前 Alpha 图片结果包含文件完全相同、解码像素相同、整体感知近似、经过 RANSAC 验证的局部裁剪/重叠，以及 Western blot、Dot blot、荧光和病理专项候选；Excel 包含完整数值、整行、连续片段/二维区域、数字片段、近似值、乱序/少量修改、线性与加减乘除关系，以及低风险统计线索。Excel 还会将同排公式或明确派生表头支持的原始列/`rescaled` 等换算列归为正常关系。选择结果后，图片可并排预览匹配区域；Western blot 摘要显示匹配条带数、结构/几何/背景/掩膜证据，Dot blot 显示斑点数、排列、强度/形态轮廓、局部图像、最低单斑点、缩放、旋转与镜像证据，荧光摘要显示中文关系、角色/通道、结构、前景重叠、互信息与配准位移，病理摘要显示中文关系、组织结构/掩膜、倍率、尺度比与变换。Excel 结果区位于上方，证据区在下方左右并排还原两侧原工作表有限上下文，黄色高亮命中单元格，同时保留完整值、误差、拟合/统计参数和逐位置配对摘要；选择结果后自动滚动到证据区。

证据区提供“聚焦匹配区域”，可将两侧预览从整图框选切换为区域放大；“复制证据摘要”将当前中文证据说明写入剪贴板。三种报告的结果表记录重点候选、次要线索或正常关系层级；HTML 还可按该层级筛选。HTML 报告是内嵌图像的单文件，可按风险和文本筛选；PDF 是带页码与图像证据的 A4 归档版。

暂停和取消采用协作式检查点：大文件正在解码或单个验证批次正在运行时，按钮会先显示“正在安全暂停/取消”，到达检查点后生效。取消不保存部分结果，并恢复扫描前的完整结果；当前不支持关闭软件后恢复未完成任务。

数据工作区提供“连续数字片段最短报警位数”3–12 调节，默认 4；图片工作区提供“内容类型”选择，默认“自动识别（推荐）”，也可指定仅通用、Western blot、Dot blot、荧光或病理，并保留“检测 Western blot 单条带相似”开关。自动模式先做低成本图片结构路由：任一 Western 区域覆盖页面至少 35%，或同页多个区域总覆盖至少 35% 且矩形联合覆盖至少 25% 时避让 Dot；其余页面只有满足斑点阵列准入才运行 Dot 专项，两个零散小 Western 区域不会屏蔽同页 Dot。命中仍只显示“局部结构”，不据此向用户宣称图片属于 Dot blot。用户显式选择 Dot blot 时绕过该自动路由并显示专项名称。图片工作区另有批次级“拆分复合图后扫描”开关和“预览拆分”按钮；启用后自动识别全部输入图片，弹窗以原图框选方式预览候选，候选默认全选，可逐项取消。未拆分出的普通图片仍以完整页面作为一个候选。第一版不提供拖拽改边界、合并或命名。数据参数区可设置额外相对容差、绝对容差、最多 20 个运算目标和连续关系中/高风险起点；默认目标为 0、1、10、100、1000，统计相似始终固定为低风险。修改任一设置都会立即使旧扫描结果失效；设置、子面板选择、结果和可选性能画像随 schema 8 项目保存、恢复，算法设置仍写入三种报告。

当前只支持所选一个或多个文件/文件夹的 Excel 全局扫描。自动识别实验组、工作表/区域手动框选和扫描前工作量预估仍待实现。

当前图片证据区仍是第一版静态预览，尚不支持同步缩放、拖动、逐匹配点/多边形显示、叠加闪烁和差异图；表格预览只读取结果附近最多 12 行 × 10 列，不替代 Excel 完整编辑器。软件不要求逐条人工复核。

结果区提供“全部/待复核/准确/误报/正常关联”筛选和四个轻量操作按钮。数据工作区另有“重点候选（推荐）/全部线索”范围选择，默认重点队列最多 50 条，并按工作簿、工作表和规则限制单一来源占比；切换到全部线索可查看低风险、未入队高/中风险和正常关系，扫描结果与报告不会因重点上限被删除。用户选择结果后可一键标记或清除；操作不弹出表单、不要求备注或全部完成。已有项目自动保存标记，未保存项目保持脏状态；同一算法版本的稳定结果重新扫描时继承标记，算法版本变化时不自动继承。顶部“导出反馈”只在当前工作区存在已标记结果时可用，支持 Excel/JSON，且不复制原始文件。

## 通用原则

- 第一版只提供中文浅色界面。
- 长任务始终显示状态、阶段、进度和可用操作。
- 高风险不使用断言式语言，明确提示需要人工复核。
- 文件错误和算法限制就地说明，不只写入日志。
- 保持原文件只读状态可见。

## 页面

### 首页

- 图片查重主入口
- 数据查重主入口
- 可选的新建、打开和保存项目
- 软件、模型和历史库状态（后续）

### 图片查重

- 只选择常规静态图片或包含图片的文件夹
- 自动/通用/Western blot/Dot blot/荧光/病理类型选择和扫描说明
- 图片专项参数
- 图片候选表和双图证据

### 数据查重

- 只选择 Excel/CSV 或包含表格的文件夹
- 全局数值扫描说明和参数
- 数据候选表、左右原工作表上下文、高亮单元格和数值关系证据

### 项目

- 拖拽文件和文件夹
- 输入清单、支持状态和失败原因
- 自动分组与手动框选
- 扫描模式和灵敏度
- 预估工作量与资源设置

### 任务

- 总体和阶段进度
- 当前处理对象
- 预计剩余时间
- 暂停、继续、取消
- 已产生结果入口

### 结果浏览

- 当前分别内嵌在图片和数据工作区
- 基本风险、类型和文件筛选
- 图像并排、叠加、闪烁、差异和匹配区域
- Excel 两侧位置、值、片段、关系和误差
- 导出当前筛选或全部结果

“准确/误报/正常关联”轻量标记用于积累本地算法调优数据。该功能不要求全部处理，不显示审核完成率，不提供审核人和强制备注，不会自动训练、上传或改变检测阈值。

#### 待确认：导出报告中的原表高亮

当前黄色命中高亮只存在于软件的数据证据预览。Excel 报告以“查重结果”和“数值证据”工作表记录文件、Sheet、坐标、完整值和关系；HTML/PDF 以结果表记录位置和关系，三种报告均未复制原工作表上下文或高亮命中单元格。

已记录的候选增强是：在 Excel、HTML、PDF 报告中增加左右并排的有限原表上下文，以黄色高亮实际命中单元格，并与界面证据布局保持一致。是否三种报告全部支持、上下文行列范围、每份报告最多嵌入多少条证据及大批量结果的文件体积，需要先与试用用户讨论确认；确认前不进入开发。

### 历史库

- 查看来源和索引状态
- 添加、移除、重新索引
- 导出、导入和合并

### 设置

- 图像与 Excel 默认灵敏度
- CPU/GPU、线程、内存和缓存
- 模型列表、版本和许可证
- 报告默认项
- 日志和软件信息

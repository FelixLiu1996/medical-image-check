# UI 与操作流程初稿

状态：需求级信息架构，视觉稿待后续设计。

## 通用原则

- 第一版只提供中文浅色界面。
- 长任务始终显示状态、阶段、进度和可用操作。
- 高风险不使用断言式语言，明确提示需要人工复核。
- 文件错误和算法限制就地说明，不只写入日志。
- 保持原文件只读状态可见。

## 页面

### 首页

- 新建项目
- 打开项目
- 最近项目
- 导入项目包
- 软件、模型和历史库状态

### 项目

- 拖拽文件和文件夹
- 输入清单、支持状态和失败原因
- 自动分组与手动框选
- 扫描模式和灵敏度
- 预估工作量与资源设置

### 任务

- 总体和阶段进度
- 当前处理对象
- 预计剩余时间
- 暂停、继续、取消
- 已产生结果入口

### 结果中心

- 图像、Excel、综合三个视图
- 基本风险、类型、文件和状态筛选
- 重复组列表
- 图像并排、叠加、闪烁、差异和匹配区域
- Excel 两侧位置、值、片段、关系和误差
- 确认重复、正常关联、误报、待定和备注
- 导出当前筛选或全部结果

### 历史库

- 查看来源和索引状态
- 添加、移除、重新索引
- 导出、导入和合并

### 设置

- 图像与 Excel 默认灵敏度
- CPU/GPU、线程、内存和缓存
- 模型列表、版本和许可证
- 报告默认项
- 日志和软件信息

## 暂缓

- 深色模式
- 自定义标签
- 高级全文搜索
- 批量人工确认
- 账号和复核人身份
